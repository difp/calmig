# CalmIG — экспериментальная настольная версия

Отдельное приложение на Rust/Tauri с локальным адаптером на основе [instagram-cli](https://github.com/supreme-gg-gg/instagram-cli). Авторы оригинального instagram-cli — Jet Chiang и James Zheng; условия и авторство сохранены в корневом LICENSE.

Запуск подготовленной локальной сборки: `./quiet-desktop/start.sh`. Нужны Node.js 22+, установленный `node_modules` и собранный `dist/quiet-bridge.js`. Это разработческая сборка для текущего пути проекта, не переносимый установщик.

Пересборка: `npm ci`, затем `./quiet-desktop/build.sh` (для Rust/Tauri нужны системные зависимости WebKitGTK). Сетевые и реальные аккаунтные сценарии не проверяются автоматически. Форматирование и тесты: `npm run build`, `npx ava --serial`, `node --test quiet-desktop/tests/ui.test.cjs`, `cargo fmt --manifest-path quiet-desktop/src-tauri/Cargo.toml -- --check`.

Основной способ входа открывает официальную страницу Instagram во встроенном окне: пароль и код вводятся на странице Instagram. После подтверждения приложение локально передаёт необходимые cookie своему адаптеру на базе неофициального instagram-cli; доступ к фотографиям и перепискам остаётся неофициальным. Браузерная сессия хранится на устройстве. Альтернативная форма передаёт пароль неофициальному клиенту; его сессия сохраняется в локальном JSON-файле с доступом владельца, без системного шифрования. При выходе приложение удаляет сессию и свой кеш. Не отправляйте пароль, код или файлы сессии в чат.

Календарь обходит список подписок, получает их публикации, отбрасывает видео и смешанные карусели и сортирует найденные фотографии по времени. Это может быть медленно на первой загрузке и может вернуть неполную выборку; прогресс и ошибки показаны на экране. Это не домашняя рекомендательная лента. Нажмите «Остановить» для прекращения после текущего запроса. Кешируются метаданные, подписи и ссылки на изображения максимум для 250 фотографий семи дней, с ограничением доступа владельцу; сами изображения загружаются по сети и ссылки могут истечь. В профиле можно очистить кеш.

Реальные возможности и поведение Instagram зависят от неофициального API и текущего аккаунта; при проверке безопасности или ограничении запросов действуйте в официальном приложении и не повторяйте попытки автоматически.
