# CalmIG desktop

Сборка и запуск: `./quiet-desktop/build.sh`, затем `./quiet-desktop/start.sh`. Для сборки нужны Rust и системные зависимости Tauri v2 (включая WebKitGTK). Node.js для работы приложения не нужен; он используется только для тестов интерфейса.

Вход открывает страницу Instagram во встроенном окне. Доступ к фотографиям и перепискам использует неофициальный Rust-клиент. Совместимую старую сессию можно восстановить по имени пользователя; несовместимая сессия требует нового входа через окно Instagram. При выходе приложение удаляет свою сессию и кеш.

Проверки перечислены в корневом README. Автоматические тесты работают на фиктивных данных и не подтверждают работу Instagram в сети.
